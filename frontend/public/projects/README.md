# Project visuals

The portfolio currently uses styled placeholders for project visuals.

1. Add your final images to this directory.
2. Open `frontend/lib/project-visuals.ts`.
3. Set the matching project's `src` value to the public path shown in `suggestedFile`.

Suggested images:

- `demand-forecasting-overview.png`: demand chart, forecast dashboard, or validation result
- `pipeline-runtime-comparison.png`: profiler output, before/after chart, or pipeline diagram
- `visual-odometry-frame.png`: drone frame with feature tracks, optical flow, or trajectory overlay
- `whisper-transcript-workflow.png`: transcript UI, waveform, or speech pipeline
- `storytelling-app-screens.png`: Flutter app screen montage

Use a wide image around 1600 x 1000 pixels when possible.
